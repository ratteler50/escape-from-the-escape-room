# Music

All by Kevin MacLeod (incompetech.com), **CC BY 4.0**: free for a public web game, credit required
(in `CREDITS.md` and on the end card). One composer keeps the game sounding of a piece. Found by
the "feel" tags in incompetech's catalogue; the agent can't hear, so the developer picks by ear.

## Picked (2026-10-22)

- **Title:** Netherworld Shanty.
- **Lair:** Graveyard Shift: the spookiest, for the first room; the rooms after it get lighter.
- **Kept for later rooms** (the developer liked all three): Sneaky Snitch, Scheming Weasel (slower)
  and Investigations, for the Gift Shop and the Break Room (slices 22–23). The finale sting is
  picked in 23.
- **Break Room** (slice 23): Sneaky Snitch: Dana tiptoes around the staff lockers and someone
  else's yogurt, which suits its tiptoeing oboe.
