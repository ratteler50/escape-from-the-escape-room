# Draft lines

Every line marked `// DRAFT:` in the game's content: 0 lines, grouped by file. Each is a line the
agent wants your opinion on: edit it at the file and line shown, or delete its `// DRAFT:` marker to keep it.

Generated by `npm run drafts`; a test fails when this file is out of date. "Look" is a look line
for an item; "Dana (option)" is a line Dana says when the player picks it in a conversation.
